# Illustrated opening creature production

Generated with the built-in image_gen tool. Nine original four-pose source sheets are saved in `assets/illustrated/{id}-source.png`; optimized runtime files are `{id}-front.webp`, `{id}-back.webp` (320×320, logical80×80), and `{id}-ow.webp` (128×64, two logical16×16 frames). All use4× rendering and true alpha. Exact full prompts are recorded below.

`node scripts/prepare-illustrated-creature.mjs SOURCE ID` crops at the transparent gutters, preserves proportions through a shared scale for each pose pair, anchors feet, and losslessly encodes WebP. `node scripts/verify-illustrated-creatures.mjs` checks all27 runtime images for dimensions/transparency and confirms distinct companion frames. Contact-sheet QA is `artifacts/illustrated-creatures-contact.png` in the species order below. All nine sets passed and were visually checked over green terrain color; no baked checkerboard was accepted. Rear poses deliberately face upper-right so the player sees their companion's back in battle.
